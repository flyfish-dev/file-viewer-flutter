# Brand asset

`file-viewer.png` is the 512×512 File Viewer project logo, copied unchanged
from the public main project's `apps/official-site/public/logo.png`. Its PNG
palette transparency is preserved. The example uses the same bytes as
`example/assets/brand.png`; both READMEs directly reference the main project's
original URL.

Source: https://github.com/flyfish-dev/file-viewer/blob/main/apps/official-site/public/logo.png
